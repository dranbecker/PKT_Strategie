# Abkürzungs- und Begriffsverzeichnis

Dieses Verzeichnis erläutert Abkürzungen und Fachbegriffe, die in den
Dokumenten dieses Repositorys verwendet werden.

## Versorgung, Klassifikation und Organisation

| Kürzel / Begriff | Bedeutung |
|---|---|
| **PKT** | Parkinson-Komplexbehandlung (multimodale Komplexbehandlung bei Morbus Parkinson) |
| **OPS** | Operationen- und Prozedurenschlüssel – amtliche Klassifikation für Prozeduren im Krankenhaus; die PKT ist unter **8-97d** kodiert |
| **Behandlungswoche** | Jeweils 7 Tage ab Aufnahme; Bezugszeitraum für die OPS-Mindestmerkmale (z. B. 7,5 Therapiestunden, Teambesprechung) |
| **ICF** | International Classification of Functioning, Disability and Health – WHO-Klassifikation der Funktionsfähigkeit (b = Körperfunktionen, s = Körperstrukturen, d = Aktivitäten und Teilhabe, e = Umweltfaktoren); siehe [Was ist die ICF?](was_ist_icf.md) |
| **WHO** | World Health Organization (Weltgesundheitsorganisation) |
| **S2k** | Leitlinien-Entwicklungsstufe: strukturierte Konsensfindung eines repräsentativen Expertengremiums |
| **DGN** | Deutsche Gesellschaft für Neurologie |
| **ANAP** | Neurologische Aufnahmeplanung – projektspezifischer Ausgangspunkt mit Fragestellungen, Vorbefunden und Sicherheitsaspekten vor der Aufnahme |
| **KIS** | Krankenhausinformationssystem; hier **Orbis** (Hersteller Dedalus) |
| **RACI** | Responsible (führt durch), Accountable (verantwortet), Consulted (wird einbezogen), Informed (wird informiert) – Methode zur Aufgabenverteilung |
| **SOP** | Standard Operating Procedure – schriftlich festgelegte Arbeitsanweisung |
| **THS** | Tiefe Hirnstimulation |
| **GdB** | Grad der Behinderung (Schwerbehindertenrecht) |
| **KKH** | SRH Kurpfalzkrankenhaus Heidelberg |

## Assessments und Fragebögen

| Kürzel | Bedeutung |
|---|---|
| **GAS** | Goal Attainment Scaling – Bewertung der Zielerreichung auf einer Skala von −2 bis +2 (−1 = Ausgangslage, 0 = erwartetes Ergebnis) |
| **MDS-UPDRS** | Movement Disorder Society – Unified Parkinson's Disease Rating Scale; **Teil III** = motorische Untersuchung |
| **PDQ-39** | Parkinson's Disease Questionnaire mit 39 Fragen – gesundheitsbezogene Lebensqualität |
| **WHODAS 2.0** | WHO Disability Assessment Schedule 2.0 – Fragebogen zu Funktionsfähigkeit und Teilhabe auf Basis der ICF |
| **FOG-Q** | Freezing of Gait Questionnaire – Fragebogen zu Gangblockaden |
| **TUG** | Timed Up and Go – Zeit für Aufstehen, 3 m Gehen, Wenden und Hinsetzen |
| **Mini-BESTest** | Mini Balance Evaluation Systems Test – Gleichgewichtstest (0–28 Punkte) |
| **MoCA** | Montreal Cognitive Assessment – kognitives Screening (0–30 Punkte) |
| **Hoehn und Yahr** | Stadieneinteilung der Parkinson-Krankheit (1–5) |
| **Schellong-Test** | Kreislauftest im Liegen und Stehen zur Erkennung einer orthostatischen Hypotonie |
| **PROM** | Patient-Reported Outcome Measure – von Patientinnen und Patienten selbst berichtetes Ergebnis (z. B. PDQ-39, WHODAS 2.0) |
| **Kernset** | Kleines, festes Set an Assessments, das bei allen Patientinnen und Patienten zu Aufnahme und Entlassung erhoben wird |

## Medikation

| Kürzel / Begriff | Bedeutung |
|---|---|
| **Levodopa (L-Dopa)** | Wichtigstes Parkinson-Medikament, Vorstufe von Dopamin |
| **COMT-Hemmer** | Hemmstoffe der Catechol-O-Methyltransferase – verlängern die Levodopa-Wirkung |
| **MAO-B-Hemmer** | Hemmstoffe der Monoaminoxidase B – verlangsamen den Dopamin-Abbau |
| **LCIG** | Levodopa-Carbidopa-Intestinalgel – Pumpentherapie über eine Sonde in den Dünndarm |
| **Apomorphin-/Foslevodopa-Pumpe** | Kontinuierliche Medikamentengabe unter die Haut (subkutan) |
| **Device-Therapie** | Gerätegestützte Therapie: Tiefe Hirnstimulation oder Pumpentherapien |
| **STRIP** | Systematic Tool to Reduce Inappropriate Prescribing – strukturiertes Verfahren zur Medikationsanalyse |
| **STRIP-PD** | Parkinson-spezifische Adaptation von STRIP in diesem Versorgungskonzept |
| **STOPP/START** | Screening Tool of Older Persons' Prescriptions / Screening Tool to Alert to Right Treatment – Listen zu potenziell ungeeigneter bzw. fehlender Medikation |
| **OTC** | Over the Counter – rezeptfreie Arzneimittel |
| **ON / OFF** | Phasen guter (ON) bzw. nachlassender oder fehlender (OFF) Medikamentenwirkung |
| **Wearing-off** | Vorzeitiges Nachlassen der Wirkung vor der nächsten Einnahme |
| **Fluktuationen** | Schwankungen der Beweglichkeit oder anderer Symptome im Tagesverlauf |
| **Dyskinesien** | Unwillkürliche Überbewegungen, häufig auf dem Wirkungshöhepunkt (Peak-dose-Dyskinesien) |
| **OFF-Dystonie** | Schmerzhafte Verkrampfung in OFF-Phasen, oft morgens |

## Therapieverfahren

| Kürzel / Begriff | Bedeutung |
|---|---|
| **ADL** | Activities of Daily Living – Aktivitäten des täglichen Lebens |
| **LSVT BIG / LOUD** | Lee Silverman Voice Treatment – intensives Training großer Bewegungen (BIG) bzw. lauter Stimme (LOUD) |
| **EMST** | Expiratory Muscle Strength Training – Training der Ausatemmuskulatur |
| **AAC** | Augmentative and Alternative Communication – Unterstützte Kommunikation |
| **KVT** | Kognitive Verhaltenstherapie |
| **CBT-I** | Cognitive Behavioral Therapy for Insomnia – kognitive Verhaltenstherapie bei Schlafstörungen |
| **Cueing** | Einsatz äußerer Reize (z. B. Rhythmus, Linien am Boden) zur Unterstützung von Bewegung |

## Symptome und klinische Begriffe

| Begriff | Bedeutung |
|---|---|
| **Freezing (of Gait)** | Plötzliche Blockade beim Gehen, z. B. beim Starten, Wenden oder an engen Stellen |
| **Orthostase / orthostatische Hypotonie** | Blutdruckabfall beim Aufstehen mit Schwindel oder Sturzgefahr |
| **Dysphagie** | Schluckstörung |
| **Sialorrhoe** | Vermehrter Speichelfluss aus dem Mund |
| **Mikrographie** | Kleiner werdende Handschrift |
| **Nykturie** | Nächtlicher Harndrang |
| **Fatigue** | Ausgeprägte, nicht durch Anstrengung erklärbare Erschöpfung |
| **Apathie** | Verminderter Antrieb und Interesse |
| **Delir** | Akut auftretende, schwankende Störung von Aufmerksamkeit und Bewusstsein |
| **Impulskontrollstörung** | Z. B. Spiel-, Kauf- oder Esssucht, meist im Zusammenhang mit dopaminerger Medikation |
| **Punding** | Zwanghaft wiederholte, zwecklose Tätigkeiten |
| **PNP** | Polyneuropathie – Schädigung peripherer Nerven |

## Begriffe des Versorgungskonzepts

| Begriff | Bedeutung |
|---|---|
| **Datenhoheit (Single Source of Truth)** | Jede Information hat genau eine verantwortliche Berufsgruppe, die sie erhebt; alle anderen nutzen sie, statt sie erneut zu erfragen |
| **Owner** | Die für ein Ergebnis oder eine Information verantwortliche Berufsgruppe |
| **Pre-Admission** | Vorbereitung vor der stationären Aufnahme (Unterlagen, Fragebögen, Medikationstagebuch) |
| **Onboarding** | Orientierung der Patientin bzw. des Patienten und der Angehörigen am Aufnahmetag |
| **Aufnahmeprofil** | Gemeinsame Zusammenführung aller Screenings der Berufsgruppen |
| **ICF-Zielmatrix** | Gemeinsame Liste der vereinbarten Behandlungsziele mit ICF-Einordnung und GAS-Skala |
| **Diagnostische Arbeitsliste** | Liste der diagnostischen Fragestellungen mit Untersuchung, Priorität, Befund und Konsequenz |
| **Screening / Assessment** | Kurze Ersteinschätzung (Screening) bzw. vertiefende, standardisierte Untersuchung (Assessment) |
| **Shared Decision-Making** | Gemeinsame Therapieentscheidung von Behandlungsteam und Patientin bzw. Patient |
| **Case Management** | Koordination der Versorgung über Berufsgruppen und Sektoren hinweg |
| **Advance Care Planning** | Vorausschauende Versorgungsplanung |
| **Capacity / Performance** | ICF: Leistungsfähigkeit unter Standardbedingungen bzw. tatsächliche Leistung im Alltag |
| **Real-World-Daten** | Daten aus der Routineversorgung statt aus kontrollierten Studien |
