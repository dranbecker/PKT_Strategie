# Checkliste Medikamenten-Review

## Aufnahme

- [ ] Vollständige Medikationsanamnese
- [ ] Exakte Parkinson-Einnahmezeiten dokumentiert
- [ ] OTC- und Selbstmedikation erfasst
- [ ] Frühere relevante Nebenwirkungen erfasst
- [ ] Motorische Fluktuationen erfasst
- [ ] Dyskinesien erfasst
- [ ] Nichtmotorische medikationsbezogene Probleme erfasst
- [ ] Adhärenz und praktische Einnahme geprüft
- [ ] Relevante Laborparameter verfügbar

## Systematische Medikationsanalyse

- [ ] Indikation jedes Medikaments geprüft
- [ ] Nutzen und Wirksamkeit geprüft
- [ ] Nebenwirkungen geprüft
- [ ] Interaktionen geprüft
- [ ] Dosierung und Organfunktion berücksichtigt
- [ ] Potenziell inadäquate Medikation geprüft
- [ ] Mögliche Unterversorgung geprüft
- [ ] Parkinson-spezifisch problematische Medikamente geprüft
- [ ] Impulskontrollstörungen berücksichtigt
- [ ] Halluzinationen/psychotische Symptome berücksichtigt
- [ ] Orthostase berücksichtigt
- [ ] Einnahmeschema auf praktische Umsetzbarkeit geprüft

## Therapieverlauf

- [ ] Therapieziele definiert
- [ ] Änderungen mit Patient besprochen
- [ ] Änderungen umgesetzt
- [ ] Wirkung evaluiert
- [ ] Nebenwirkungen evaluiert
- [ ] Interprofessionelle Beobachtungen berücksichtigt

## Entlassung

- [ ] Finale Medikation überprüft
- [ ] Exakte Einnahmezeiten festgelegt
- [ ] Medikationsplan erstellt
- [ ] Änderungen im Arztbrief begründet
- [ ] Patient/Angehörige informiert
- [ ] Erforderliches Monitoring definiert
- [ ] Ambulante Weiterbehandlung sichergestellt
