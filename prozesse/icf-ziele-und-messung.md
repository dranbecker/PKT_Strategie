# ICF-Ziele und Messung

> **Status:** Konzept

Behandlungsziele der Parkinson-Komplexbehandlung werden **ICF-orientiert
formuliert** (siehe [Was ist die ICF?](../was_ist_icf.md)) und auf zwei
Ebenen gemessen:

1. **Individuell:** Goal Attainment Scaling (GAS) je vereinbartem Ziel
2. **Standardisiert:** ein schlankes, festes **Kernset** an Assessments
   zu Aufnahme und Entlassung sowie jährliche Verlaufsmessung

So wird sichtbar, ob die *persönlich bedeutsamen* Ziele erreicht wurden
**und** ob sich die Behandlung in vergleichbaren Kennzahlen
niederschlägt.

## Zielformulierung

### Vorgehen

1. Die Screenings der Berufsgruppen liefern Problemfelder (Tag 1–2).
2. Die Patientin bzw. der Patient benennt, was im Alltag am wichtigsten
   ist (ggf. mit Angehörigen).
3. In der Zielvereinbarung (bis Tag 3, Moderation PA) werden **3–5
   Ziele** festgelegt und priorisiert.
4. Jedem Ziel wird eine **verantwortliche Berufsgruppe** zugeordnet;
   weitere Berufsgruppen können beitragen.

### Struktur eines Ziels

| Ebene | Beispiel |
|---|---|
| **Körperfunktion (b)** | Verbesserung der Schrittlänge und Bewegungsamplitude |
| **Aktivität (d)** | Selbstständiges Gehen in der Wohnung ohne Freezing an Türschwellen |
| **Teilhabe (d)** | Wieder selbstständig den Weg zum Bäcker gehen |
| **Kontext (e / personenbezogen)** | Rollator vorhanden; hohe Motivation; Ehefrau unterstützt |
| **Verantwortlich** | PT (mitwirkend: ET, PN) |

## Goal Attainment Scaling (GAS)

Für jedes Ziel wird bei der Zielvereinbarung eine fünfstufige Skala
festgelegt:

| Stufe | Bedeutung | Beispiel „Weg zum Bäcker" |
|---|---|---|
| **−2** | deutlich schlechter als Ausgangslage / keine Veränderung bei Verschlechterungsrisiko | Gehen nur mit Begleitung in der Wohnung |
| **−1** | Ausgangslage (Aufnahmestatus) | Gehen in der Wohnung mit Rollator, häufiges Freezing |
| **0** | **erwartetes Ergebnis** | Gehen in der Wohnung mit Cueing-Strategie ohne Freezing |
| **+1** | etwas besser als erwartet | zusätzlich 200 m draußen mit Rollator |
| **+2** | deutlich besser als erwartet | Weg zum Bäcker selbstständig |

- **Festlegung:** bis Tag 3
- **Zwischenstand:** in jeder wöchentlichen Teambesprechung
- **Abschlussbewertung:** Tag 12–13
- **Auswertung:** GAS-T-Wert über alle Ziele (Aggregation durch PA)

> Die Skalenstufen werden vorab konkret und beobachtbar formuliert. So
> wird die Bewertung zwischen Berufsgruppen vergleichbar.

## Kernset-Assessments

Das Kernset ist bewusst klein gehalten. Weitere Assessments werden nur
bei spezifischer Fragestellung im Rahmen der fachlichen Vertiefung
eingesetzt.

| Bereich | Instrument | Owner | Pre-Admission | Aufnahme | Entlassung | Jährlich |
|---|---|---|---|---|---|---|
| Lebensqualität | **PDQ-39** | PA | ● | | ● | ● |
| Funktionsfähigkeit/Teilhabe (ICF) | **WHODAS 2.0** | PA | ● | | ● | ● |
| Freezing of Gait | **FOG-Q** | PA | ● | | ● | |
| Motorik | **MDS-UPDRS Teil III** | PA (ÄD freigegeben) | | ● | ● | (Ambulanz) |
| Funktionelle Mobilität | **Timed Up and Go (TUG)** | PT | | ● | ● | |
| Gleichgewicht | **Mini-BESTest** | PT | | ● | ● | |
| Kognition (Screening) | **MoCA** | NP | | ● | bei Auffälligkeit | |
| Schlucken | standardisiertes Schluckscreening | LO | | ● | bei Auffälligkeit | |

**Grundsatz:** Fragebögen werden einmal erhoben und von allen genutzt
(siehe [Datenhoheit](raci-matrix.md#datenhoheit-single-source-of-truth)).
Kein Instrument wird von zwei Berufsgruppen parallel erhoben.

## Nutzung der Ergebnisse

- **Teambesprechung:** GAS-Zwischenstand je Ziel statt freier
  Verlaufsberichte
- **Arztbrief:** Zielmatrix mit GAS-Ergebnis und Kernset-Vergleich
  Aufnahme/Entlassung als strukturierter Abschnitt
- **Qualitätsmanagement:** Aggregation über alle Behandlungsfälle
  (z. B. Anteil erreichter Ziele, mittlere PDQ-39-Veränderung)
- **Langzeitverlauf:** jährliche PDQ-39- und WHODAS-2.0-Erhebung in der
  Nachsorge zeigt, ob Effekte nachhaltig sind, und liefert eigene
  Real-World-Daten (vgl. [Studienlage](../Studienlage.md))
